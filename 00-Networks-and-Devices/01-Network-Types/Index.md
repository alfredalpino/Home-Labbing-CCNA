# Network Types

How engineers classify networks by **reach**, **media**, and **architecture**.

## Analogy

> Sorting networks is like sorting **transport systems**:
> - Bicycle path in your yard → [[PAN]]
> - City streets → [[LAN]] / [[WLAN]]
> - Metro rail across a city → [[MAN]]
> - Interstate highways → [[WAN]]
> - Private tunnel under the highways → [[VPN]]
> - Someone else’s warehouse you rent → [[Cloud]] / [[SAN]] (specialized)

## By geographic / functional scope

| Note | One-line idea |
|------|----------------|
| [[LAN]] | Local, high-speed, usually one org/site |
| [[WAN]] | Long-distance links between sites |
| [[MAN]] | City-scale between LAN and WAN |
| [[WLAN]] | LAN over radio (Wi‑Fi) |
| [[PAN]] | Personal space (Bluetooth, USB tethering) |
| [[SAN]] | High-speed storage fabric |
| [[VPN]] | Encrypted overlay across another network |
| [[Cloud]] | On-demand remote resources as a network destination |

## By architecture

| Note | One-line idea |
|------|----------------|
| [[Client-Server Network]] | Clear requesters vs dedicated providers |
| [[Peer-to-Peer Network]] | Peers share roles; no required central server |
