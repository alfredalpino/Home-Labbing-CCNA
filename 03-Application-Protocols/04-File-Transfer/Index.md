# File Transfer

Moving configs, images, captures, and firmware between hosts — safely.

## Notes in this section

| Note | Role |
|------|------|
| [[FTP-SFTP]] | Classic FTP vs encrypted SFTP (usually over [[SSH]]) |

## Ops tip

Prefer **SFTP/SCP** for anything with credentials or running-config contents. Plain FTP still appears on old gear — know it, don’t default to it.
