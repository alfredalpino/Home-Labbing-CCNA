# Prompt Templates

**Prerequisite:** `01`–`05` are already loaded (project knowledge, paste, or `@ai-context`).

Copy a template, replace `[BRACKETS]`, send.

---

## 1) Plan my day (rhythm lock)

```
Using my AI context (spine, DROP list, ~6h lab / 2h docs / 1h apps), plan today.
Current week: [W1|W2|W3|W4]
Active lab: [LAB-0X]
Applications focus: [GCC country or "remote Network/NOC"]
Constraints: [fatigue / appointments / none]
Return: hour-by-hour, one anti-goal, definition of done for tonight.
```

---

## 2) Design / extend a lab

```
Act under my guardrails. Work on [LAB-0X — title].
Status now: [Queued|In progress|partial]
I need: [topology | configs | verify steps | failure cases | README outline | ticket story]
Environment: [Packet Tracer | Azure | Bash/Python | mixed]
Do not invent completed results. Give copy-pasteable steps and a monorepo folder layout.
```

## 3) Lab README writer

```
Draft a README for [LAB-0X] for my public monorepo.
Include: objective, topology, prerequisites, build steps, verify commands, failure cases, recovery, ticket-story paragraph, next lab link.
Tone: operator runbook, not academic essay.
Assume certs/skills from identity doc; do not claim production customer impact I didn't state.
```

## 4) Troubleshooting coach (ticket style)

```
Symptom: [what fails]
Lab/context: [LAB-0X or Tikona-style edge]
What I already checked: [list]
Give: isolate order (L1→L2→L3→service), exact show/verify commands, likely causes ranked, escalation notes if upstream.
No fluff. No new cert recommendations.
```

## 5) Resume bullet upgrade (facts only)

```

```
