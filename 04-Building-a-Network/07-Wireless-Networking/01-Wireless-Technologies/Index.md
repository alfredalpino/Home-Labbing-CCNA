# Wireless Technologies

Radios beyond campus Wi‑Fi — still “wireless,” but different jobs than [[WLAN]] / [[Access Points]].

## Analogy

> If Wi‑Fi is the **office intercom**, these notes are the **other radios in the building and beyond**: earbuds and tap badges ([[Bluetooth-NFC]]), smart-light messengers ([[Zigbee-Z-Wave]]), city cellular taxis ([[Mobile-Networks]]), phone sprinkler hotspots ([[Hotspot-and-Tethering]]), and long-haul pigeons/airmail ([[LoRaWAN-Satellite]]).

## Notes

| Note | One-line idea |
|------|----------------|
| [[Bluetooth-NFC]] | PAN: peripherals & tap interactions |
| [[Zigbee-Z-Wave]] | IoT meshes; hubs bridge to IP |

## When to use which (pocket guide)

| Need | Reach for |
|------|-----------|

| Headset / tap-to-pay | [[Bluetooth-NFC]] |
| Battery sensors / smart building | [[Zigbee-Z-Wave]] / [[LoRaWAN-Satellite]] |
| Branch backup / phone outage path | [[Mobile-Networks]] · [[Hotspot-and-Tethering]] |
| Remote site no fiber | [[LoRaWAN-Satellite]] · [[Mobile-Networks]] |
